# 🍱 Food Ordering Web Page

This project is a frontend food ordering web application built using **React** and **Tailwind CSS**, with **Redux** integrated for managing the cart functionality. It was developed to strengthen my skills in building component-based UIs and implementing global state using Redux Toolkit.

## 🔧 Tech Stack

- **React JS** – Component-driven development
- **Redux Toolkit** – Cart state management
- **Tailwind CSS** – Utility-first styling approach

## ✨ What I Built

- Designed reusable components for menu layout and food cards  
- Implemented a Redux-powered cart feature to manage selected items  
- Styled the entire application using Tailwind CSS for clean and consistent UI  
- Practiced integrating assets (like cart icons) and handling basic UI logic

## 💡 Key Learnings

- React component structure and props management  
- Using Redux Toolkit for predictable state handling  
- Tailwind's utility classes for faster and cleaner CSS
